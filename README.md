# Fox Helper / Лисёнок-помощник

A desktop fox that follows your daily schedule, reminds you of important things and dates, looks after your breaks, suggests drawing ideas and opens programs. Windows.

Настольный лисёнок: живёт по вашему расписанию, напоминает о важном и о датах, следит за перерывами, подкидывает идеи для рисунков и открывает программы. Windows.

**Download / Скачать:** [latest release](https://github.com/Cangrida/foxhelper/releases/latest) → `FoxHelper-win64.zip`, unpack, run `FoxHelper.exe`. After that the app updates itself. / распаковать, запустить `FoxHelper.exe`, дальше программа обновляется сама.

## What's new / Что нового
